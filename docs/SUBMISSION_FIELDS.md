# Submission field answers

## Startup Prize fields

Only complete these fields if you are opting into the Startup Prize **and** are submitting for an
incorporated organization with a corporate email address.

- **Organization name:** use the exact legal name of the incorporated organization.
- **Corporate email:** use an email on the organization's domain, not a personal email.
- If those conditions do not apply, leave both optional fields blank and do not represent Rootstory
  as incorporated.
